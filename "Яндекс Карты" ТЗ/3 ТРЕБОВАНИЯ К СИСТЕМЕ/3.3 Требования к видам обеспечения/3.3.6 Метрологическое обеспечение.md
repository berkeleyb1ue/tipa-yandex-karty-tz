При использовании средств измерений (в части определения координат, скорости движения и т. п.) должна обеспечиваться точность, достаточная для выполнения функций навигации и маршрутизации согласно показателям, приведённым в п. 4.1.3. Специальных метрологических требований, подлежащих поверке, для программной части системы не предъявляется.
