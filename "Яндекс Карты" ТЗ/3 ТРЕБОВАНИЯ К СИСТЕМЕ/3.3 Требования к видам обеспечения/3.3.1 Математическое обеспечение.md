Должны применяться апробированные алгоритмы построения кратчайших/оптимальных маршрутов на графах (например, модификации алгоритмов Дейкстры, A*, контракции иерархий), алгоритмы прогнозирования трафика на основе статистических моделей и/или моделей машинного обучения, а также алгоритмы геокодирования и нечёткого текстового поиска.
