1) Клиентские приложения разрабатываются для платформ iOS и Android (нативно либо с использованием кроссплатформенных технологий), а также в виде веб-приложения, совместимого с современными браузерами (не менее двух последних мажорных версий)
2) серверная часть разрабатывается с использованием технологий, обеспечивающих требуемую производительность, масштабируемость и надёжность (конкретный стек технологий определяется исполнителем и согласовывается с заказчиком);
3) используемое программное обеспечение должно быть либо лицензионным, либо распространяться на условиях свободных лицензий, совместимых с целями проекта.
