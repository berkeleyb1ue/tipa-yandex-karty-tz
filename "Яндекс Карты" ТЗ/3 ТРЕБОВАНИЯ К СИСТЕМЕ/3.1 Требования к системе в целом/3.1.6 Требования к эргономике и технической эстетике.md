1) Интерфейс приложения должен соответствовать современным принципам UX/UI-проектирования, обеспечивать интуитивно понятную навигацию и минимальное количество действий для выполнения основных сценариев (поиск, построение маршрута);
2) должна быть обеспечена поддержка светлой и тёмной темы оформления;
3) интерфейс должен адаптироваться под различные размеры экранов мобильных устройств и веб-браузеров;
4) должна быть обеспечена доступность интерфейса для пользователей с ограниченными возможностями (поддержка screen-reader, увеличение шрифта, контрастные схемы) в соответствии с рекомендациями WCAG 2.1 уровня AA;
5) голосовые подсказки навигации должны быть чёткими, поддерживать несколько языков и учитывать особенности произношения топонимов.
